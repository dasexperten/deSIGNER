## Thresholds (WCAG 2.x)

| Context | Minimum |
|---|---|
| Text (any size on this board) | **≥ 4.5 : 1** |
| UI components, focus indicators, state glyphs | **≥ 3.0 : 1** |

## The law

Contrast is **computed, not trusted**: `api/a11y.test.mjs` (17 tests) parses the hex
tokens out of `ui.html` and re-derives every WCAG ratio on each CI run — change a
token and the math re-votes. `api/design-tokens.test.mjs` freezes the Owner verdicts.
Any new color/text pairing must pass the matrix above; any allowlist addition
requires an Owner verdict **and** the ratio written next to it in code.
