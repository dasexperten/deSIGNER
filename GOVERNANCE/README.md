# GOVERNANCE — the corrective layer

deSIGNER is not just an archive; it's a guide that stops repeating mistakes.

| File | Role |
| --- | --- |
| `corrections-log.md` | One entry per caught design mistake — what was wrong, which rule prevents recurrence |
| `direction.md` | Polish and direction decisions — the owner's standing design direction |

## The learning loop

1. **Capture** — every corrected design mistake (bad banner, broken mobile
   view, off-brand render, packaging error, drift between a working copy and
   deSIGNER) gets one entry in `corrections-log.md` at the moment it's caught.
2. **Distill** — monthly, entries that repeat are promoted into `FOUNDATION/`
   rules and into the affected skill sources in `SKILLS/`.
3. **Result** — the rule layer grows from real failures, and skills inherit
   the fixes at their source.
